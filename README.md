# Enterprise ITSM & Cloud Operations Analytics Dashboard

## Project Overview

Designed and developed a multi-page Power BI dashboard covering:

- Executive ITSM Reporting
- Engineer Performance Analytics
- Operations Monitoring
- Cloud Infrastructure Health

## Technologies Used

- Power BI
- DAX
- Data Modeling
- KPI Analytics
- SLA Monitoring

## Dashboard Pages

### Executive Summary
- Total Tickets
- Open Tickets
- Resolved Tickets
- SLA Compliance
- Resolution Metrics

### Engineer Performance Dashboard
- Tickets by Engineer
- Team Distribution
- Workforce Analytics

### Operations Dashboard
- Category Analysis
- Priority Analysis
- Resolution Time Analysis

### Cloud Operations Dashboard
- VM Availability
- Backup Success Rate
- Critical Alerts
- Capacity Utilization

## Key Features

- Relational Data Modeling
- DAX Measures
- KPI Tracking
- Trend Analysis
- Interactive Reporting
